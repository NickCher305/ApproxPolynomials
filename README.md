# ApproxPolynomials

Программа для сравнительного анализа методов приближения функций с использованием различных полиномов интерполяции.


## Установка

### 1. Клонирование репозитория

```bash
git clone <https://github.com/NickCher305/ApproxPolynomials>
cd ApproxPolynomials
```

### 2. Установка зависимостей Python

```bash
pip install -r requirements.txt
```

**Состав requirements.txt:**
```
numpy>=1.21.0
matplotlib>=3.5.0
jupyter>=1.0.0
```

### 3. Установка LaTeX (опционально, для автоматической компиляции PDF-отчёта)

Если LaTeX не установлен, программа создаст:
- Исходный `.tex` файл (можно скомпилировать вручную или онлайн)
- Полноценный HTML-отчёт с MathJax

**Windows — MikTeX:**
1. Скачайте установщик с [miktex.org/download](https://miktex.org/download)
2. Запустите установку, выберите **"Install for all users"**
3. На этапе настройки выберите **"Yes"** для автоматической установки пакетов

**Linux (Ubuntu/Debian) — TeX Live:**
```bash
sudo apt-get install texlive-latex-base texlive-latex-extra texlive-fonts-recommended texlive-lang-cyrillic
```

**macOS — MacTeX:**
```bash
brew install --cask mactex-no-gui
```

## Использование

### Консольный интерфейс

#### Встроенные функции
```bash
# Базовый запуск — все функции, узлы 5/10/15/20, обе сетки
python main.py

# Исследование конкретной функции
python main.py --function runge --nodes 8 12 16 20

# Только равномерная сетка, выбранные методы
python main.py --grid uniform --methods lagrange cubic

# Все функции с расширенным набором узлов
python main.py --function all --nodes 5 10 15 20 25 30

# Без компиляции PDF (только LaTeX + HTML)
python main.py --no-pdf
```

#### Пользовательская функция (NEW)
```bash
# Простая функция на указанном отрезке
python main.py --custom-function "sin(pi * x) * exp(-x)" --custom-interval 0 2

# Полином
python main.py --custom-function "x**3 - 2*x + 1" --custom-interval -1 1 --grid both

# Совместно со встроенными функциями
python main.py --function runge --custom-function "exp(-x^2)" --custom-interval -2 2

# С указанием имени для сохранения файлов
python main.py --custom-function "abs(sin(5*x))" --custom-interval 0 3.14 --custom-name my_func

# Функция с модулем (используйте ^ для степени)
python main.py --custom-function "sin(x^2)" --custom-interval -2 2
```

#### Полный список параметров
```
--function, -f      Выбор функции: sin, runge, abs, exp_sin, all (по умолчанию: all)
--nodes, -n         Количество узлов: список целых чисел (по умолчанию: 5 10 15 20)
--grid, -g          Тип сетки: uniform, chebyshev, both (по умолчанию: both)
--methods, -m       Методы: lagrange, newton, linear, cubic (по умолчанию: все)
--output, -o        Директория для результатов (по умолчанию: results)
--no-pdf            Не компилировать PDF-отчёт
--custom-function, -cf   Пользовательская функция в виде строки
--custom-interval, -ci   Границы отрезка [a, b] (по умолчанию: 0 1)
--custom-name, -cn       Имя для файлов (по умолчанию: custom_function)
```

## Возможности

### Методы интерполяции (все реализованы с нуля)
- **Полином Лагранжа** — барицентрическая форма (численно устойчивая)
- **Полином Ньютона** — с разделёнными разностями и схемой Горнера, поддержка добавления узлов без пересчёта
- **Линейный сплайн** — кусочно-линейная интерполяция
- **Кубический сплайн** — естественные граничные условия, метод прогонки для трёхдиагональной СЛАУ

### Встроенные тестовые функции

| Функция                 | Отрезок      | Назначение                                             |
|-------------------------|--------------|--------------------------------------------------------|
| $\sin(x)$               | $[0, 2\pi]$  | Гладкая периодическая — тест на сходимость             |
| $\frac{1}{1+25x^2}$     | $[-1, 1]$    | Функция Рунге — демонстрация феномена Рунге            |
| $\|x\|$                 | $[-1, 1]$    | Функция с изломом — тест на явление Гиббса             | 
|-------------------------|--------------|--------------------------------------------------------|
| $e^{-x} \cdot \sin(5x)$ | $[0, 2]$     | Затухающие колебания — тест на разрешающую способность |


### Пользовательские функции (Ключевой момент!)
Вводите произвольную функцию в виде строки от `x`:
```bash
python main.py --custom-function "sin(pi*x)*exp(-x)" --custom-interval 0 2
```
Поддерживаются: `sin`, `cos`, `tan`, `exp`, `log`, `sqrt`, `abs`, `sinh`, `cosh`, `tanh`, `pi`, `e`, операторы `+`, `-`, `*`, `/`, `**` (или `^`).

### Типы сеток
- **Равномерная** — равноотстоящие узлы
- **Чебышёвская** — сгущение к краям, минимизация феномена Рунге (автоматическая сортировка)

### Метрики качества
- **Равномерная (Чебышёвская) норма** $||f-P||_{\infty}$
- **Среднеквадратичная ($L_2$) норма** $||f-P||_2$

- Таблица погрешностей (CSV)
- LaTeX-отчёт с автоматической компиляцией в PDF
- Резервный HTML-отчёт с MathJax (не требует LaTeX)

## Научная ценность

Программа демонстрирует:

1. **Феномен Рунге** — расходимость глобальной полиномиальной интерполяции на равномерной сетке для функций с особенностями
2. **Преимущество сетки Чебышёва** — сгущение узлов к краям минимизирует осцилляции
3. **Устойчивость сплайнов** — кусочная интерполяция не подвержена феномену Рунге
4. **Численную эквивалентность** — полиномы Лагранжа и Ньютона дают идентичный результат
5. **Скорость сходимости** — количественные оценки для каждого метода

Весь математический код написан **с нуля**, без использования готовых библиотек интерполяции. SciPy может применяться опционально для верификации.

## Ответы на наиболее важные вопросы

**Как ввести свою функцию?**
Используйте флаг `--custom-function`. Пример: `--custom-function "exp(-x)*cos(2*pi*x)" --custom-interval 0 3`. Поддерживаются все основные математические функции NumPy.

**Почему Лагранж и Ньютон дают одинаковый результат?**
Математически это один и тот же интерполяционный полином. Различаются только формы записи и способы вычисления. Их совпадение подтверждает корректность обеих реализаций.

**Почему сплайны не работают на чебышёвской сетке?**
Начиная с версии 1.1, узлы Чебышёва автоматически сортируются по возрастанию, поэтому сплайны корректно работают на обеих сетках.

**Как скомпилировать PDF-отчёт без LaTeX?**
Загрузите файл `results/report.tex` на [Overleaf](https://www.overleaf.com) (бесплатный онлайн-редактор LaTeX) и нажмите «Скомпилировать». Или используйте автоматически создаваемый HTML-отчёт.

## Возможные проблемы и их решение

| Проблема | Решение |
|----------|---------|
| `python` не распознаётся | Попробуйте `python3` вместо `python`; проверьте галочку «Add Python to PATH» при установке |
| `pip` не распознаётся | Попробуйте `pip3` вместо `pip` или `python -m pip install -r requirements.txt` |
| Ошибка `ModuleNotFoundError: No module named 'numpy'` | Выполните `pip install -r requirements.txt` ещё раз, убедитесь что вы в папке проекта |
| Ошибка «Узлы должны быть строго возрастающими» | Убедитесь, что используете последнюю версию (в ней чебышёвская сетка сортируется автоматически) |
| Графики не сохраняются | Проверьте права доступа к папке `results/`, она создаётся автоматически при первом запуске |
